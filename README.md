Metodologia educativa manipulativa per introduir el pensament computacional a partir d’una ruleta de seqüències, tapissos de joc i robots compactes.
Iniciada a Educació Infantil (I5) per treballar seqüenciació i oralitat mitjançant el conte, i dissenyada per escalar-se a primària i secundària mantenint la mateixa base metodològica.
